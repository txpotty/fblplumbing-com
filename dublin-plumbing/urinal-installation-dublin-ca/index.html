    Rough-in decides whether the finish goes smoothly. The carrier, 2 inch waste, 3/4 inch supply and vent all go in to the spec sheet before drywall. The rough gets inspected before cover. Then the walls close.

    Urinal Rough-In for New Restrooms in Dublin

    Tenant improvements need rough-in before the walls close. We space urinals 30 inches apart and 15 inches from side walls, then set carriers and run all the lines. We stay in touch with the GC daily. Rough inspection comes first.

    Drainage and Venting for Urinals in Dublin, CA

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. Venting stops gurgle and odor. We tie in within code distance.

    Sensor Urinal Installation in Dublin, CA

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.

    Urinal Upgrades and Water Savings in Dublin, CA

    Older urinals often use 1.5 gallons or more per flush. Replacing them with 0.5 or 0.125 gallon models on the existing carrier, and swapping the flush valve to match, cuts water use sharply in any restroom that sees regular traffic. Ask your water utility about rebates. We provide the model numbers you need.

    American Standard and Kohler Urinal Installation in Dublin

    American Standard and Kohler make the china we install most. Models like the Washbrook and the Bardon come in versions from 0.125 to 1.0 gallons per flush, and each one needs a flush valve matched to that rating or the bowl will either splash or not rinse clean. Matching is simple with the spec sheet. We order both together.
