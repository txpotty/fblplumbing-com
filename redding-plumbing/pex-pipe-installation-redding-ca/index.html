    PEX-A vs. PEX-B Installation in Redding

    Homeowners ask us which one is better, and the honest answer depends on the job. PEX-A makes tighter bends, can be heat-fixed if it kinks, and its fittings flow better, while PEX-B is cheaper and its crimps hold just as well when each one is gauged. Both last decades. For tight attics we lean toward PEX-A.

    Uponor PEX System Installation in Redding

    Uponor's ProPEX system is PEX-A joined with an expansion tool and a cold-expansion ring. The tech expands the pipe and ring together, pushes the fitting in, and the plastic shrinks back around the barb over the next few seconds, tighter than when it started. No crimp tool to calibrate. The fittings have a wide bore, so flow loss through each joint stays low.
