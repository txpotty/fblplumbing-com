    Flush Valve Urinal Installation in Visalia, CA

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. We set the volume to the bowl. Wrong settings stain bowls.

    Sloan Flush Valve Installation in Visalia, CA

    Sloan Royal valves are on most commercial urinals we see. Sensor versions mount the same way. Battery models need no wiring.

    ADA-Compliant Urinal Installation in Visalia

    At least one urinal in a public restroom with more than one usually has to be accessible. ADA units need a rim at or below 17 inches, a 13-1/2 inch projection and 30 by 48 inches of clear floor. The flush handle has to be easy to reach. We mark it all during rough-in.

    Waterless Urinal Installation in Visalia

    Waterless urinals save the most water and need the most discipline. They use a cartridge or a layer of sealing liquid that lets urine pass while blocking sewer gas, and the cartridge has to be swapped on schedule or the restroom starts to smell. Your custodial team needs training. We show them how.

    Waterless Cartridge Urinals in Visalia

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. We set up a schedule with you. Spare cartridges should stay on site.

    Sensor Urinal Installation in Visalia, CA

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    Drainage and Venting for Urinals in Visalia, CA

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. Venting stops gurgle and odor. We tie in within code distance.
