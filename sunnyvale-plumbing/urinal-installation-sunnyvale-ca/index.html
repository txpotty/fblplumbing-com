    Waterless Urinal Upgrades in Sunnyvale

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Some codes want the supply left in place. That allows a future change back.

    Residential Urinal Plumbing in Sunnyvale, CA

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Urinal Replacement and Upgrades in Sunnyvale

    Cracked or stained urinals are worth replacing. Cracked china leaks eventually and heavy scale rarely comes clean, so a new bowl on the old carrier is usually best. We check the carrier bolts first. Rusted bolts get replaced.

    Old Urinal Removal and Replacement in Sunnyvale

    Old urinals come off harder than they went on. Corroded hanger bolts and a flush valve seized to the spud mean we come prepared to cut, and we protect the wall tile while we do it so the new fixture does not sit against broken edges. We never reuse the old gasket. The flange gets cleaned to bare metal.

    Urinal Brands We Install in Sunnyvale, CA

    Brand choice is mostly about parts support. We recommend brands whose valves and cartridges are easy to get locally, so repairs never wait. We install all of them. Spec sheets come first.

    Flush Valve Urinal Installation in Sunnyvale, CA

    Flush valve urinals are the commercial standard. A flushometer from Sloan or Zurn delivers a measured volume from a 3/4 inch supply with no tank, and it recovers instantly for the next user, which matters in a stadium or school restroom. The volume matches the fixture rating. Wrong settings stain bowls.

    Flushometer Urinal Installation in Sunnyvale

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handles can go left or right. ADA units need the handle within reach.

    Sensor Urinal Installation in Sunnyvale, CA

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.
