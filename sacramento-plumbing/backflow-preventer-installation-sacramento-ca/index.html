    Reduced Pressure Zone (RPZ) Assembly Installation in Sacramento

    Two independent checks and a relief valve make up an RPZ. When pressure between the checks gets too close to supply pressure, the relief opens, dumping water to the floor or a drain so nothing can pass upstream, which is why we never bury one in a pit in Sacramento. Brands include Watts and Febco.

    Double Check Valve Assembly Installation in Sacramento

    Double check assemblies work for low-hazard connections such as many fire lines and some irrigation. They have two spring-loaded checks and test cocks for annual certification, and since they do not discharge water, they can go in a vault or below grade where local rules allow, sized so the pressure loss stays small. We size for flow.

    Double Check Valve Assembly (DCVA) Installation in Sacramento

    A double check valve assembly, or DCVA, uses two spring-loaded checks in series with four test cocks. It handles low-hazard connections like many fire sprinkler lines, and because it does not discharge water, it can go in a vault where local rules allow it, sized so it does not rob your system of pressure in Sacramento. Test cocks stay reachable.
